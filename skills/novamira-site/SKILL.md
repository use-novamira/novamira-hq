# Novamira site operations

Use the installed desktop application's `novamira-hq site-cli` command. Do not
install a standalone CLI or external runtime.

Before site work, run `novamira-hq site-cli guide get core` and follow its
version-matched instructions. Load `novamira-hq site-cli guide get core --full`
when command examples or recovery guidance are needed. Run site operations only
through `novamira-hq site-cli ...`; hosting operations use `novamira-hq ...`.

If the command is unavailable, open Novamira HQ → Settings → Connect your agents
to enable or repair command access, then restart the terminal and agent.
